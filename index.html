Original planning script (60 s)

[0–5s] HOOK Slam laptop shut, grab car keys. “Two hundred dollars a month. That’s not an AI subscription… that’s a car payment.”

[5–12s] CAR BIT “This gets me to work. This gets me undefined is not a function. Same price. One of them has seats.”

[12–25s] PROBLEM Cheap models guess; they read your code like a text message from your ex.

[25–40s] FIX LSP draws the red squiggly lines. Wire it into Kilo: wrong type, missing import, function doesn’t exist. The model stops guessing and starts fixing.

[40–48s] DISTILLED Distilled/open models + a compiler shouting answers = smarter. Brains for pennies, glasses for free.

[48–55s] BLACK HOLE No LSP: tokens go in, nothing comes out, bank account spaghettified.

[55–60s] CLOSE Start from somewhere. Kilo, a cheap model, LSP on. Keep the car. Jingle keys.

Before you film / publish: proof check

Make sure your Kilo setup really passes LSP diagnostics to the agent. Kilo’s newer runtime shares roots with OpenCode, which can feed LSP diagnostics back to the agent; OpenCode’s docs also say it is not always a net positive. Record a short screen capture of one real fix as proof (the on-camera 4K clip could be paired with it in a v2).
