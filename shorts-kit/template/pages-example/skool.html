❓ What is LSP?

In one sentence

LSP = Language Server Protocol: an open standard (introduced by Microsoft for VS Code in 2016) that lets an editor or tool talk to a language server that really understands a programming language.

Language servers exist for most languages, e.g. typescript-language-server, pyright (Python), gopls (Go), rust-analyzer (Rust).

What it gives you

  • 🔴 Diagnostics: the red squiggles (errors and warnings)
  • 🧭 Go to definition, find references
  • 💡 Hover types, autocomplete, rename

Same answers a compiler or type-checker would give, available while you type.

Why it matters for a cheap model

  1. The agent edits a file.
  2. The language server checks it and replies with exact problems: “line 12: string is not assignable to number”, “missing import”.
  3. The model reads facts instead of guessing, so cheaper (distilled / open) models behave smarter.

⚠️ Not a magic switch. It only helps if your tool actually passes the diagnostics to the agent (OpenCode does this out of the box; Kilo's newer runtime shares its roots, so verify on your setup), the right language server must be installed, and OpenCode's own docs note it is not always a net positive (extra noise, tokens, time). Test it on your own code and share what you see.
